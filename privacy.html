取得する情報と権限

運用者本人の許可に基づき、YouTubeアカウントの表示（youtube.readonly）と、YouTubeアナリティクスレポートの表示（yt-analytics.readonly）の権限を使用します。

対象チャンネルと動画のID、タイトル、公開・処理状態、公開日時、尺、累計再生、日次の再生・視聴時間・平均視聴・登録者増減、流入元、取得可能な維持率を収集します。視聴者個人のアカウント情報やパスワード、コメント本文、収益情報は収集対象ではありません。

利用目的

公開失敗の検知、実績記録、制作の進行確認、次回制作への改善候補の検討に使用します。動画の投稿・削除や公開設定の変更には使用しません。

保存先と共有

認証情報は運用者のPCのアクセスを制限したファイルと、運用者の非公開GitHubリポジトリのActions Secretsに保存します。観測ログは運用者のPCと同じ非公開リポジトリに保存します。

自動取得はGoogleとGitHubのサービスを使用します。運用者が依頼したAIアシスタントに、分析・制作支援のため観測結果を提示する場合があります。自動収集スクリプト自体は外部のAI APIを呼び出しません。取得データや認証情報をこの公開ページに掲載することはありません。広告配信やデータ販売には使用しません。

保存期間と削除

初期の自動取得期間は2026年11月1日までです。期間終了後も比較・再開のため観測ログが保存されます。接続解除だけでは保存済みログは削除されません。削除が必要な場合は、運用者がローカルコピー・Git履歴・GitHub側の保存状況を確認して該当データを処理します。

接続の取り消し

Googleアカウントの接続管理からアクセス許可を取り消せます。以後、認証に失敗した取得は停止します。日次取得はGitHubの設定からも無効にできます。

Googleユーザーデータ

Google APIから受け取った情報の使用および他のアプリへの移転は、限定使用要件を含むGoogle API Services User Data Policyに従います。

このページ自体について

独自の広告・アクセス解析・Cookieによる追跡は設置していません。ホスティングサービスによるアクセスログ等の処理は、そのサービスのポリシーに従います。
